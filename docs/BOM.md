# Electronics BOM / 电子物料

The current detailed procurement list is [BOM.zh-CN.md](../pcb/keyfield-fpc/BOM.zh-CN.md), with an [editable CSV](../pcb/keyfield-fpc/BOM.csv). It covers one 18-left / 17-right keyboard, existing holder interfaces and the optional FFC sensor.

Quantities of key sockets/diodes/FFCs also apply to the selected 35-key FR4 assembly; FR4 has separate left/right thumb branches and does not use the FPC JP1 hand selector. Populate only the chosen thumb branch. Mechanical backers/supports differ between FR4 and FPC; do not combine those entries blindly.

中文：采购请看详细 BOM。FR4 与 FPC 的 35 键核心元件数量相同，但拇指选型方式和承托不同；库存、排线最终长度及实际主控堆叠仍需确认。
