# Printed FPC direct supports — V31

Four one-piece supports for bare 0.11 mm V27 FPC and Kailh sockets; no separately bonded FR4 backers in this modeled stack. Use the [integrated upper shells](../integrated-fr4/README.md) and the existing V7 bottoms. These replace the FR4 main/thumb retainers, not the upper shells.

Clearance coupons: [0.15](coupon_gap_15.3mf), [0.25](coupon_gap_25.3mf), [0.35 mm](coupon_gap_35.3mf). Print and measure before selecting the real assembly tolerance; these are alternatives, not a claim that one is already validated.

The models are print-oriented, geometry-only, at 100% scale. [Original orientation/round-trip checks](checks/) and [physical trial log](physical-trial-log.csv) are retained. K1C / 0.4 mm nozzle / PLA or PETG is the user's intended setup; no machine profile or G-code is embedded.
